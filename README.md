## 📌 About

Gadag Info is a premium digital destination designed to display local updates, events, and information in an incredibly structured and user-friendly format. The platform moves beyond traditional informational sites by delivering a highly curated, editorial-style reading experience.

By combining cutting-edge frontend technologies like Next.js App Router and GSAP with 4K visual assets and bilingual localization (English/Kannada), the platform establishes a world-class digital presence for the region's rich cultural, historical, and modern landscape.

## 🚀 Getting Started

### Prerequisites

- **Node.js** ≥ 18.x
- **npm** or **yarn**

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/deepakparagi/gadag_info.git

# 2. Navigate into the project
cd gadag_info

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

The app will be available at `http://localhost:3000`

---

## 📋 Available Scripts

| Script | Command | Description |
|:---|:---|:---|
| **Dev Server** | `npm run dev` | Starts the Next.js development server on port 3000 |

| **Start** | `npm run start` | Serves the production build locally |
